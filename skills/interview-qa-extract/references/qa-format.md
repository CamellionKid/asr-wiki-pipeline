## YAML

```yaml
title: "<公司> <岗位> <轮次>｜一问一答"
date: YYYY-MM-DD
type: interview-qa
company:
position:
round:
interview_role: self | observer
pipeline_id:
source: "[[Raw 笔记名]]"
related:
  - "[[<活动名>｜文档地图]]"
tags:
  - kb/layer/wiki
  - kb/type/interview-qa
```

缺值写空或省略，不要填猜测。

## 压缩禁区

一问一答是 ASR 的**完整转写重排**。允许压缩的只有：

| 位置 | 压缩规则 |
| --- | --- |
| 题干标题 | ≤40 字压缩句 |
| 问答清单 | 一行一题 |
| 说话人表依据列 | 一句话 |

其余全部逐句保留清洗稿原文：

- 问题原文：面试官的完整提问，含铺垫、自我纠正、举例。
- 追问：每次追问完整原文 + 时间戳。
- 回答原文：候选人完整回答，按语义分段；跑题段、犹豫段、自我修正段都保留。
- 可删除的仅纯填充词与无语义重复，删除后信息量不变。

完整性三条同时满足才算通过（字数比 >100% 是重复信号，不是通过信号）：句级覆盖 ≥ 90%；同一题问答不得含相同段落、全文引用重复率 ≤ 5%；不得残留 `〔…〕`、TODO、待补。不达标就是发生了隐性简化或重复灌水，回头补齐或拆开。

## 正文结构

```markdown
# <公司> <岗位> <轮次>｜一问一答

> [!abstract] 这篇笔记是什么
> 从清洗稿切出的完整问答，正文逐句保留原文，不评分、不推断。原文见 [[Raw 笔记]]。

## 说话人

| 标签 | 角色 | 依据 |
| --- | --- | --- |
| Speaker 1 | 面试官 / 候选人 / `[U]` | 转写内证据或用户指定 |

## 问答清单

1. Q01 压缩题干
2. Q02 …

## 非问答片段

- 时间戳 + 完整原文（寒暄、设备说明、无法配对独白）

## 逐题

### Q01 压缩题干
```

## 单题模板

```markdown
### Q01 <不超过40字的题干>

- **时间**：`HH:MM:SS`–`HH:MM:SS`（无时间戳则写「未提供」）
- **提问人**：Speaker N / 面试官姓名或 `[U]`
- **turn_type**：`interviewer-question` | `candidate-question` | `mixed`
- **问题原文**：
  > 清洗稿整段搬入，保留待确认标记；多段提问按时间戳分段
- **追问**（可空）：
  - `HH:MM:SS` 完整原文
- **回答原文**：
  > 清洗稿整段搬入，按语义分段；不压缩、不概括、不截断
- **未决**：`[名词待确认]` / 说话人不明 / 音频缺口
```

`candidate-question` 时，「问题原文」是候选人问的，「回答原文」是面试官答的，同样完整。

## 证据标记

只在切分判断上使用，不引入评价：

| 标记 | 含义 |
| --- | --- |
| `[F-S]` | 转写中确有此句 |
| `[U]` | 角色、题界、时间或专名未决 |
| 上游标记 | `[名词待确认]`、`[lang-mismatch]` 原样保留 |

不要把清洗稿里的推测写成已核验事实。
